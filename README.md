# New Experiment

按设计文档 `main.pdf` 搭建经济模拟环境。文档共六类问题，目前只做了第一类。

## 1. 第一类环境（代际与养老金）做了什么

一句话：把设计文档第一类的世界规则写成了一个能跑的模拟环境，所有角色按固定规则行动，没有训练。

- **世界**：80 个年龄队列（21 到 100 岁）的人口、一个总量生产函数、带结余基金的现收现付养老金。一步是一年，一个回合 200 年。
- **家庭**：每个年龄 × 四种行为类型（理性 R、现时偏好 P、学习型 A、社会型 S）。每年决定存多少，区别在于怎么预期自己将来的养老金。
- **养老金当局**：每 5 年可以调一次缴费率、替代率、退休年龄。基金不够发时自动削减当年待遇。
- **规则型决策**：家庭把一生资源平摊到剩余寿命；当局要么不动，要么按基金多少调缴费率。
- **验证**：账目每年闭合（残差 1e-15 量级）；人口回声周期模拟值 31.2 年，理论值 31.3 年。
- **结果**：老龄化场景下，缴费率走出 0.14 → 0.22 → 0.08 → 0.24 的长周期（约 135 年），基金在第 156 年耗尽，之后 24 年待遇被削减。这是一个随机种子的结果。

还没做的：会优化的家庭（文档的 M1）、强化学习（M2）、财政当局与投票（G2、G3）。
