# 第一类环境：代际与养老金（rule-based 版）

按设计文档 `../main.pdf` 第一类实现的模拟环境。所有角色按固定规则行动，没有强化学习，也没有动态规划。

本文分两部分：第 1 节讲项目结构，第 2 节讲环境设定。

## 1. 项目结构

### 1.1 目录

```
olg_pension_env/
  cfg/                 配置。base.yaml 是全部默认参数；其余每个文件是一个场景，只写要改的键
  data/                三个输入表（存活率、进入率、年龄效率）和生成它们的 make_data.py
  entities/            世界规则，每个文件一个对象
      population.py      人口：各年龄人数怎么逐年变化
      firm.py            生产：产出、利率、工资
      households.py      家庭：预算、消费、效用、预期的更新
      pension.py         养老金当局：基金收支、自动平衡、政策调整的约束
  env/
      env_core.py        把上面四个对象串起来，推进一年
      observations.py    每个角色能看到什么
  agents/rule_based/   决策规则（以后换成 RL 时，替换的就是这一层）
      households.py      家庭怎么决定储蓄比例
      pension.py         当局怎么调政策
  runner.py            跑一个回合：燃烧期、主运行、保存
  main.py              命令行入口
  calibrate.py         校准：调一个参数，让资本产出比等于目标值
  plot.py              画图
  validate/            检验：check_identities.py 会计恒等式，check_echo.py 人口回声
  report/              报告 report.tex / report.pdf，以及报告用的图
  output/<场景>/       运行结果
```

分层的原则：`entities/` 和 `env/` 是世界怎么运转，`agents/` 是角色怎么做决定。两者只通过观测和动作交换信息。

### 1.2 一年是怎么跑的

```
runner.burn_in()                              燃烧期，得到初始状态（见 2.9）
runner.run(T) 每年重复：
    action = pol_agent.get_action(pol_obs)        仅在决策年（t 是 5 的倍数）
    hh_obs = env.begin_year(action)               步骤 1-4
    s      = hh_agent.get_action(hh_obs)          家庭选储蓄比例
    pol_obs, rewards, info = env.end_year(s)      步骤 5-8
runner.save()                                 写入 output/<场景>/
```

一年分成两次调用，是因为家庭要先看到当年的工资和利率才能做决定。

### 1.3 运行

环境用现成的 conda 环境 `EconGym`（只需要 numpy、pandas、scipy、omegaconf、matplotlib）。所有命令在 `olg_pension_env/` 目录下运行。

```bash
conda activate EconGym
python main.py --scene aging                 # 燃烧期 + 200 年主运行，结果存到 output/aging/
python plot.py --scene aging                 # 画 overview.png 和 cohorts.png
python validate/check_identities.py --scene aging
python validate/check_echo.py
python calibrate.py --scene level2_R --param households.tilt --target 3.0
python main.py --scene aging --set pension.kappa=0.5 seed=2      # 临时改参数
```

现成的场景：

| 场景 | 家庭规则 | 类型占比 R/P/A/S | 政策规则 | 用途 |
|---|---|---|---|---|
| `level1_fixed` | 固定储蓄比例 | 1/0/0/0 | 不动 | 跑通与对账 |
| `level2_R` | 按预期平摊 | 1/0/0/0 | 不动 | 基准 |
| `level2_mixed` | 按预期平摊 | 0.4/0.2/0.2/0.2 | 看基金调缴费率 | 四种类型 + 政策调整 |
| `underfunded_mixed` | 按预期平摊 | 0.4/0.2/0.2/0.2 | 不动，缴费率 0.12 | 基金耗尽、类型分化 |
| `aging` | 按预期平摊 | 0.4/0.2/0.2/0.2 | 看基金调缴费率 | 人口每年收缩 0.5% + 第 10 年生育冲击 |

### 1.4 输出

每次运行在 `output/<场景>/` 下生成：

| 文件 | 内容 |
|---|---|
| `series.csv` | 每年一行的总量：产出、资本、基金、缴费率、触发、福利、各类型预期、账目残差等 |
| `cohorts.npz` | 每年、每个年龄、每种类型的消费、资产、储蓄比例、预期 |
| `summary.json` | 一个回合的摘要 |
| `config.yaml` | 本次运行实际用的全部参数 |
| `overview.png`、`cohorts.png` | `plot.py` 画的总量路径图和分年龄图 |

目前 `output/` 里只保留了 `aging` 的结果，对它的说明见 `report/report.pdf`。

## 2. 环境设定

### 2.1 时间

一步是一年，一个回合 200 年。环境里有三个快慢不同的时钟：

| 时钟 | 频率 | 内容 |
|---|---|---|
| 快 | 每年 | 生产率冲击；家庭决策 |
| 中 | 每 5 年 | 养老金当局调整政策 |
| 慢 | 几十年 | 人口年龄结构的变化 |

每年按固定顺序执行八步：

1. 人口更新：每个队列老一岁，一部分人去世，新队列进入。
2. 生产率冲击实现。
3. 如果是决策年，当局调整政策。
4. 由资本和劳动算出利率与工资；结算基金，不够发时触发自动平衡。
5. 家庭选择储蓄比例，得到消费和下一年的资产。
6. 结算下一年的资本。
7. 各类型更新预期。
8. 计算奖励，核对账目。

### 2.2 人口

模型年龄 j = 1..80，对应真实年龄 21 到 100 岁。N[j, t] 是第 t 年年龄 j 的人数。

```
N[j+1, t+1] = psi[j+1] * N[j, t]        psi 是活到下一岁的概率；100 岁之后全部去世
N[1, t+1]   = sum_j f[j] * N[j, t]      f 是进入率
```

- **进入率 f[j]**：年龄 j 的每个人在下一年带来多少个 21 岁的新进入者。父母 20 到 45 岁生育，孩子 21 年后进入模型，所以 f 在模型年龄 21 到 46 为正，平均 31。
- **人口增速**：f 的整体水平由 `population.growth_target` 决定。1.0 是总人口不变，0.995 是每年收缩 0.5%。
- **生育冲击**：`population.fertility_shock` 可以让某一年的新队列多出一个比例。
- **人口回声**：新队列多了，约 31 年后他们的孩子进入时又会多一批，如此衰减振荡。这是环境里唯一自带的长周期。

默认数据下，21 岁的人平均还能活 58 年，活到 65 岁的概率是 0.82。人口不变时抚养比（退休人数 / 在职人数）是 0.39，`aging` 场景是 0.46。

### 2.3 生产与价格

```
Y = Z * K^alpha * L^(1-alpha)
log Z = g * t + z,    z' = rho * z + sigma * eps      生产率 = 趋势增长 + 随机冲击
r = alpha * Y / K - delta                             利率
w = (1 - alpha) * Y / L                               每单位有效劳动的工资
K = 上一年所有家庭的储蓄 + 养老基金
L = 在职者的 N[j] * e[j] * 工时 之和
```

- **年龄效率 e[j]**：不同年龄的人干活的效率不同，21 岁是 0.47，48 岁最高（1.25），64 岁是 0.91。
- **工时**：固定为 1/3，家庭不选择劳动。
- **长期增长率**：人均产出每年增长 g / (1 − alpha) = 2.24%。

### 2.4 家庭

一个家庭代表“一个年龄 × 一种行为类型”的所有人。同一年龄内各类型的占比由配置给定。

每年的预算：

```
x  = (1 + r) * a + (1 - tau_p) * w * e[j] * 工时 * 1[在职] + b * 1[退休] + tr
c  = (1 - s) * x        消费
a' = s * x              带到下一年的资产
```

| 符号 | 含义 |
|---|---|
| x | 当年可支配的全部资源 |
| a | 年初资产，等于上一年存下的 a'；21 岁进入时为 0 |
| tau_p | 养老金缴费率 |
| b | 每个退休者当年领到的养老金 |
| tr | 意外遗产：当年去世者留下的资产连同利息，平均分给所有在世者 |
| s | 储蓄比例，家庭唯一的动作，范围 0 到 0.99 |

因为 s 不小于 0，家庭不能借钱。效用是 `u = c^(1-sigma)/(1-sigma) - chi * 工时^(1+1/varphi)/(1+1/varphi)`；工时固定，所以第二项是常数。

### 2.5 家庭的决策规则与四种类型

**规则**（`households.rule = expectation`）：把一生的资源平摊到剩余寿命。

```
c = tilt * (x + 未来工资之和 + kappa_e * 平均工资 * 未来领养老金的年数) / 期望剩余寿命
c 不超过 x
s = 1 - c / x
```

- 未来工资和领养老金的年数都按存活概率加权，价格和政策取当年的值并假设以后不变。
- **kappa_e** 是家庭对自己退休后替代率的预期（替代率 = 养老金 / 在职者平均工资）。预期越低，现在花得越少、存得越多。
- **tilt = 1.132** 是校准出来的，使只有 R 型时资本产出比等于 3。

四种类型共用这条规则，区别在 kappa_e 怎么更新，以及两处修正：

| 类型 | 预期 kappa_e | 其他修正 |
|---|---|---|
| R 理性基准 | 等于当前规则的替代率 | 无 |
| P 现时偏好 | 同 R | 消费多 15% |
| A 学习型 | 每年向“信号”靠拢 5% | 无 |
| S 社会型 | 先像 A 一样更新，再与同龄人的平均预期按 0.7 : 0.3 混合 | 储蓄比例与上一年同龄人的平均按 0.7 : 0.3 混合 |

补充说明：

- **进入时的预期**：每个新队列进入时，四种类型的 kappa_e 都等于当时规则的替代率。
- **A、S 型的信号**：他们认为制度实际能兑现的替代率。基金占产出比不低于 0.5 时，信号是当年实际发放的替代率；低于 0.5 时不再相信承诺，信号改为“缴费率 / 抚养比”，即不动用基金、只靠当年缴费能发的水平（不超过实际发放）。
- **S 型的同龄人**：同一年龄的四种类型按占比加权。储蓄参照的是上一年的值，因为决策时别人当年的选择还没有发生。

另有一条只用于对账的简单规则（`households.rule = fixed`）：在职者固定 s = 0.691，退休者每年花掉 x / 期望剩余寿命。

### 2.6 养老金当局

制度是带结余基金的现收现付制：当年在职者的缴费用来发当年退休者的养老金，多出来的进基金，不够的从基金里补。

```
平均工资 wbar = w * L / 在职人数
每人待遇 b    = kappa * wbar                      kappa 是替代率
基金 F'       = (1 + r) * F + tau_p * w * L - b * 退休人数
```

**自动平衡**：如果按上式算出 F' 小于 0，就把当年待遇削减到恰好 F' = 0，并记一次“触发”。回合不终止。

政策工具：

| 工具 | 范围 | 每次最多调整 | 默认初值 |
|---|---|---|---|
| 缴费率 tau_p | 0 到 0.4 | 0.02 | 0.14 |
| 替代率 kappa | 0 到 1 | 0.05 | 0.40 |
| 退休年龄 | 60 到 70 岁 | 1 岁 | 65 |

政策只在 t 是 5 的倍数的年份生效，其余年份不变。

两种规则型决策：

- `pension.rule = fixed`：一直沿用初始政策。
- `pension.rule = fund_ratio`：决策年看基金占产出比，低于 0.2 就把缴费率加 0.02，高于 2.0 就减 0.02，替代率和退休年龄不动。

人口不变时，收支恰好平衡的缴费率是 替代率 × 抚养比 = 0.4 × 0.39 = 0.156。默认的 0.14 略低于它。

### 2.7 奖励

| 角色 | 每年的奖励 |
|---|---|
| 家庭 | 当年的效用 u |
| 养老金当局 | W − 1 × 1[当年触发自动平衡]，W 是所有在世者效用的人均值 |

现阶段没有训练，奖励只是算出来并记录。

### 2.9 初始状态与回合

主运行开始前先跑一段不计入结果的**燃烧期**，用来得到起点：

1. 人口取给定增速下稳定的年龄分布，每人资产相同。
2. 政策固定、冲击关闭、基金占产出比固定在 0.5，用同一套家庭规则一年年往下跑。
3. 资本产出比不再变化时停止（通常 100 到 160 年）。
4. 把各水平量缩回生产率为 1 的尺度，时间归零。

回合固定 200 年。基金耗尽不终止回合，只触发自动平衡。

读结果时要知道三点：

- **产出和福利的水平没有含义**。它们取决于人口规模和生产率的单位，只有比率（资本产出比、基金占产出比等）和增长率有意义。
- **起点不是严格的稳态**。燃烧期把基金占比固定住，主运行放开后它会漂移。原因是利率高于增长率：政策不变时，基金多一点就越滚越大，少一点就越来越少直到耗尽，没有稳定的中间状态。
- **结果对随机种子和参数敏感**，同样出于上一条原因。目前的结果都只用了一个种子。

### 2.11 和设计文档的差别

- 家庭不求解优化问题，用 2.5 节的规则代替；四种类型的区别只落在预期和两处修正上。
- 预期按替代率形成，不按金额。
- 劳动固定，所以每年不需要迭代求工资。
- 自动平衡在家庭决策之前确定，家庭看到的是实际发放额。
- 只有养老金当局一个政策角色：没有财政当局（劳动税、国债、政府支出都为 0），没有投票。
- 家庭是队列的代表，同一年龄同一类型内没有收入和财富差异。
